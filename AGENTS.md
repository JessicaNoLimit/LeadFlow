# LeadFlow — Lorenzo Bellucci Studio

## Descripción del proyecto

LeadFlow es una aplicación web moderna creada para "Lorenzo Bellucci Studio", un estudio fotográfico premium ficticio.

La plataforma combina:

- Una web pública de fotografía y portfolio
- Un CRM privado para gestionar solicitudes de presupuesto y posibles clientes

El objetivo es simular una herramienta profesional real, con una arquitectura moderna, una experiencia visual elegante y una estructura escalable.

---

# Objetivos principales

La aplicación debe permitir:

- Mostrar la web pública del estudio fotográfico
- Permitir que posibles clientes soliciten presupuestos
- Gestionar leads desde un panel privado
- Hacer seguimiento de solicitudes mediante estados

---

# Stack tecnológico

Frontend:
- Next.js (App Router)
- TailwindCSS

Backend:
- Route Handlers de Next.js

Base de datos:
- Supabase

Autenticación:
- Better Auth o solución personalizada

Integraciones externas:
- Resend API para emails automáticos

Despliegue:
- Vercel
